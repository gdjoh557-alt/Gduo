# 🛡️ حارس المجموعة — Telegram Group Guard

بوت حماية وإدارة مجموعات تيليجرام باللغة العربية. يعمل بـ Python و`python-telegram-bot` مع قاعدة بيانات SQLite، لذلك لا يحتاج إلى API key إضافي أو خدمة قاعدة بيانات خارجية.

## المزايا

- صلاحيات متدرجة: المالك، الأدمن الرئيسي، الأدمن، والمشرف المساعد.
- تفعيل مستقل لكل مجموعة عبر الأمر العربي `تفعيل` بعد ترقية البوت مشرفًا.
- منع تنفيذ العقوبات على المالك أو رتبة أعلى.
- طرد، حظر دائم، حظر مؤقت، كتم مؤقت، رفع العقوبة، وحذف فردي/جماعي.
- تحذيرات مع حد قابل للتعديل وإجراء تلقائي عند الوصول للحد.
- مكافحة الروابط الدعائية، الكلمات الممنوعة، والفيضانات.
- كابتشا حسابية عند دخول الأعضاء مع طرد تلقائي عند انتهاء المهلة.
- قفل طارئ للمجموعة، قائمة موثوقين، قواعد، ترحيب، وسجل إجراءات.
- انتهاء تلقائي للعقوبات المؤقتة عبر مهمة تعمل كل 30 ثانية.
- لا توجد أسرار داخل الكود؛ `BOT_TOKEN` و`ADMIN_ID` يقرآن من متغيرات البيئة.
- أوامر عربية بدون `/` مثل `حظر` و`كتم` و`رفع مشرف` و`معلومات` و`اضف رد`.

## التشغيل على استضافة خارجية

1. أنشئ بوتًا عبر `@BotFather` وخذ `BOT_TOKEN`.
2. اعرف رقم حسابك في تيليجرام، وضعه في `ADMIN_ID`، وليس username.
3. ارفع محتويات هذا المجلد إلى الاستضافة.
4. ثبّت الحزم:

   ```bash
   pip install -r requirements.txt
   ```

5. أضف Secrets/Environment Variables:

   ```text
   BOT_TOKEN=...
   ADMIN_ID=123456789
   ```

6. شغّل:

   ```bash
   python -m group_guard_bot.bot
   ```

قاعدة البيانات تحفظ في `data/bot.sqlite3`. على الاستضافة التي لا تملك تخزينًا دائمًا اربط Persistent Volume أو ستضيع الإعدادات عند إعادة التشغيل.

## إعداد تيليجرام

- أضف البوت إلى المجموعة كمشرف.
- فعّل له صلاحيات حذف الرسائل، تقييد الأعضاء، حظر الأعضاء، ودعوة المستخدمين عند الحاجة.
- إذا كانت المجموعة تستخدم Privacy Mode، عطّلها من `@BotFather` عبر `/setprivacy` حتى يستطيع البوت فحص الرسائل.
- بعد الترقية، اكتب `تفعيل` من حساب مشرف حتى يبدأ البوت بالعمل في تلك المجموعة.
- أوامر الإدارة تعمل داخل المجموعة المفعّلة فقط، بينما `/start` و`/help` يعملان في الخاص أيضًا.

## أمثلة سريعة

```text
/promote @user moderator
/promote @user admin
/warn @user نشر روابط
/tban @user 2h سبام متكرر
/mute @user 30m
/addword كلمة_ممنوعة
/setspam delete
/setflood 5 10 mute
/setcaptcha on
/setrules يمنع نشر الروابط والإعلانات
/lock
/unlock
```

### الردود التلقائية

رد على رسالة نصية أو صورة أو فيديو ثم اكتب:

```text
اضف رد مرحبا
حذف رد مرحبا
تعديل رد مرحبا
الردود
```

يدعم النص المحفوظ المتغيرات `/id` و`/user` و`/name` و`/fullname`
و`/mention` و`/group` و`/date` و`/time`.

يمكن استهداف العضو بالرد على رسالته بدل كتابة المعرف. السبب اختياري، وعند عدم كتابته يستخدم البوت عبارة `سبب غير محدد`.

## تنبيه مهم

هذا مشروع حماية عام، وليس بديلًا عن مراجعة صلاحيات البوت وإعدادات المجموعة. اختبر الأوامر في مجموعة تجريبية أولًا، ولا تضع `BOT_TOKEN` داخل Git أو داخل ملفات المشروع.
